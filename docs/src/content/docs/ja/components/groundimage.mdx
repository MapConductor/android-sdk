GroundImage は、地図上に地理的に配置される画像オーバーレイです。フロアプラン、衛星画像、気象オーバーレイ、または特定の地理座標に固定する必要がある画像ベースのデータを表示するのに便利です。

## パラメータ

- **`bounds`**: 画像を配置する地理的な矩形境界（`GeoRectBounds`）
- **`image`**: 表示する drawable 画像（`Drawable`）
- **`opacity`**: 透明度レベル、0.0（透明）から 1.0（不透明）まで（デフォルト: `0.5f`）
- **`id`**: GroundImage のオプションの一意識別子（`String?`）
- **`extra`**: GroundImage に付加する追加データ（`Serializable?`）

## ベストプラクティス

1. **画像品質**: 高解像度の画像を使用しても、スケーリングが良好なことを確認してください
2. **透明度の使用**: 下の地図が見える適切な透明度レベルを選択してください
3. **境界の正確さ**: 画像の境界が地図上の実際の場所と正確に一致することを確認してください
4. **パフォーマンス**: 複数の大きな画像を同時に使用する場合、パフォーマンスへの影響を監視してください
5. **キャッシング**: 繰り返し読み込まれる画像は、パフォーマンスのためにキャッシュしてください
6. **動的な読み込み**: 大きな画像セットの場合、表示可能な画像のみを動的に読み込むことを検討してください
7. **Z-Index**: 複数の画像を重ねる場合、正しいレイヤー順序を維持してください
