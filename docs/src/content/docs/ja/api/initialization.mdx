このセクションでは、異なる地図SDKに対して MapConductor を適切に初期化および設定する方法について説明します。

## 基本的な初期化

### Gradle 依存関係

`build.gradle.kts` に MapConductor を追加します:

<GradleDependencies
  commentForChooseProvider="地図SDKを選択"
  bomVersionPlaceholder="{BOM_MODULE_VERSION}"
/>
