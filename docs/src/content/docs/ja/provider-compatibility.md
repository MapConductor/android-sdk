# プロバイダ互換性

このページでは、MapConductor がサポートしている各地図プロバイダで利用可能な機能の一覧と、挙動の違いについて説明します。

## 対応状況の概要

MapConductor は、Google Maps、Mapbox、HERE、ArcGIS、MapLibre をサポートしています。主要なマップ機能（マーカー、円、ポリライン、ポリゴンなど）は、すべてのプロバイダでできる限り同じ API で扱えるように設計されています。

一部の機能（例: GroundImage）は Google Maps のみ対応など、プロバイダ固有の制約があります。

## 主な機能と互換性

以下は代表的な機能の対応状況の例です。

- **マップ表示**: すべてのプロバイダでサポート
- **マーカー**: すべてのプロバイダでサポート（アイコン表現やアニメーションの仕様はプロバイダごとに若干異なります）
- **円 / ポリライン / ポリゴン**: すべてのプロバイダでサポート
- **GroundImage**: 現時点では Google Maps のみ

詳細な機能差分は、各コンポーネントのドキュメント（例: [Marker コンポーネント](/ja/components/marker) や [Polyline コンポーネント](/ja/components/polyline)）も参照してください。

## イベントとジェスチャ

カメラ移動イベントやタップイベントなどのインタラクション API は、可能な限り共通のインターフェースになるように設計されていますが、以下のような違いが存在する場合があります。

- 一部のプロバイダでは、特定のイベントが提供されない
- イベントの発火タイミングや頻度が SDK によって異なる

MapConductor 側でラップし、統一的な挙動になるようにしていますが、微妙な差異が問題となるユースケース（精密なトラッキングなど）では、実際の挙動を確認することを推奨します。

## パフォーマンスと制限

大量のマーカーやポリゴンを表示する場合、プロバイダごとに描画性能やメモリ使用量が異なります。MapConductor は可能な範囲で最適化を行っていますが、以下の点に注意してください。

- モバイル端末の性能と組み合わせて、適切なズームレベルやクラスタリング戦略を選択する
- プロバイダ独自の制限（最大オブジェクト数、レイヤー数など）を考慮する

より高度な最適化については、[Experimental / Marker Strategy](/ja/experimental/marker-strategy) も参照してください。
