MapConductor は、マップとそのコンポーネントに対するユーザーインタラクションのイベント処理を包括的に提供します。
マップのイベントは MapView コンポーネントで処理し、オーバーレイのイベントは各 State に設定します。

<MapViewEventHandlersSignature />

## マップイベント

### マップ初期化

- マップの読み込みが完了し、インタラクションの準備ができたときに呼び出されます。

<OnMapLoadedSignature />

-  例

<OnMapLoadedExample commentForPrint="Map loaded" />

### マップインタラクション

- ユーザーがマップ（オーバーレイではない部分）をタップしたときに呼び出されます。

<OnMapClickSignature />

**イベントデータ**: `GeoPointInterface` - タップされた地理座標

-  例

<OnMapClickExample commentForPrint="Map clicked at:" />

## マーカーイベント

すべてのマーカーイベントは、マーカーの現在の状態を含む `MarkerState` オブジェクトを受け取ります。

### クリックイベント

- マーカーがタップされたときに呼び出されます。

<OnMarkerClickSignature />

-  例

<OnMarkerClickExample commentForPrint="Marker clicked at:" />

### ドラッグイベント

- **`onDragStart`**: ドラッグ開始時に呼び出されます
- **`onDrag`**: ドラッグ中に継続的に呼び出されます
- **`onDragEnd`**: ドラッグ終了時に呼び出されます

- マーカーアニメーションの開始時と終了時に呼び出されます。
