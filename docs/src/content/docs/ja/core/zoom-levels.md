---
title: "Zoom Levels（ズームレベル）"
---

`Zoom Levels` ドキュメントでは、ズームレベルと表示スケールの関係、および `MapCameraPosition` の `zoom` パラメータの扱いについて説明します。

## ズームレベルの目安

- ズームレベル 5〜7: 都道府県・州レベル
- ズームレベル 10〜12: 都市レベル
- ズームレベル 15〜17: 街区・建物レベル
- ズームレベル 18 以上: 詳細レベル

正確なスケールはプロバイダごとに異なりますが、MapConductor は API レベルで共通の `zoom` 値を扱えるようにしています。

## パディングとの組み合わせ

`MapCameraPosition` の `paddings` を設定すると、UI コンポーネント（ボトムシートやサイドパネル）に隠れないように地図の表示範囲を調整できます。
