MarkerAnimation は、地図上のマーカーに対するスムーズな遷移と視覚効果を提供します。アニメーションは、マーカーの外観、位置の変更、ライフサイクルイベントに適用できます。

## MarkerAnimation インターフェース

<MarkerAnimationInterface />

## アニメーションタイプ

### 位置アニメーション

座標を更新する際に、マーカーの位置変更をスムーズにアニメーション化します。

<PositionAnimationClass defaultDuration={1000} />

#### 使用例

<AnimatedMarkerExample
  latitude={37.7749}
  longitude={-122.4194}
  commentForAnimateMarker="マーカーを新しい位置にアニメーション"
  commentForMapViewUsage="MapView を GoogleMapView、MapboxMapView などの選択した地図SDKに置き換えてください"
  commentForClickTrigger="アニメーションをトリガー"
  commentForAnimateStart="マーカーのアニメーション開始"
  commentForAnimateEnd="マーカーのアニメーション終了"
  animationDuration={1500}
/>

### スケールアニメーション

強調や状態遷移のためにマーカーのサイズ変更をアニメーション化します。

<ScaleAnimationClass defaultDuration={500} />

#### 使用例

<ScaleAnimationExample
  latitude={37.7749}
  longitude={-122.4194}
  initialScale={1.0}
  commentForAnimateScale="スケール変更をアニメーション"
  commentForMapViewUsage="MapView を GoogleMapView、MapboxMapView などの選択した地図SDKに置き換えてください"
  expandScale={1.5}
  collapsedScale={1.0}
  animationDuration={300}
/>

### フェードアニメーション

表示・非表示効果のためにマーカーの不透明度を制御します。

<FadeAnimationClass defaultDuration={800} />

#### 使用例

<FadeAnimationExample
  latitude1={37.7749}
  longitude1={-122.4194}
  latitude2={37.7849}
  longitude2={-122.4094}
  commentForAnimateOpacity="不透明度の変更をアニメーション"
  buttonLabelWhenVisible="マーカーを隠す"
  buttonLabelWhenHidden="マーカーを表示"
  commentForMapViewUsage="MapView を GoogleMapView、MapboxMapView などの選択した地図SDKに置き換えてください"
  animationDuration={600}
/>

### バウンスアニメーション

マーカーが表示されるとき、または操作されるときにバウンス効果を作成します。

<BounceAnimationClass defaultBounceHeight={50} defaultDuration={1000} />

#### 使用例

<BounceAnimationExample
  latitude={37.7749}

  commentForMapViewUsage="MapView を GoogleMapView、MapboxMapView などの選択した地図SDKに置き換えてください"

  animationDuration={800}

## パフォーマンスの考慮事項

### アニメーション最適化

1. **同時アニメーションを制限**: 同時アニメーションが多すぎるとパフォーマンスに影響
2. **適切な期間を使用**: 非常に長いアニメーションは遅く感じる可能性があります
3. **効率的なインターポレータを選択**: 一部のインターポレータは計算コストが高い

## ベストプラクティス

### アニメーションガイドライン

1. **フィードバックを提供**: アニメーションを使用してユーザーの操作に視覚的なフィードバックを提供
2. **コンテキストを維持**: アニメーションはユーザーが空間的な関係を理解するのに役立つべきです
3. **一貫性を保つ**: アプリケーション全体で類似したアニメーションスタイルを使用
4. **アクセシビリティを考慮**: アニメーションを減らすまたは無効にするオプションを提供

## トラブルシューティング

### 一般的な問題

1. **アニメーションが開始しない**: `MarkerState.setAnimation()` が呼び出されていることを確認
2. **ギクシャクした動き**: インターポレータの選択とフレームレートを確認
3. **メモリリーク**: マーカーが削除されたときにアニメーションをクリア
4. **パフォーマンス問題**: 同時アニメーションを制限し、短い期間を使用
