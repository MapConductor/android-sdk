Una GroundImage es una superposición de imagen posicionada geográficamente en un mapa. Es útil para mostrar planos de plantas, imágenes de satélite, superposiciones meteorológicas o datos basados en imágenes que deben anclarse a coordenadas geográficas específicas.

## Parámetros

- **`bounds`**: Límites rectangulares geográficos donde se posiciona la imagen (`GeoRectBounds`)
- **`image`**: Imagen dibujable para mostrar (`Drawable`)
- **`opacity`**: Nivel de opacidad de 0.0 (transparente) a 1.0 (opaco) (predeterminado: `0.5f`)
- **`id`**: Identificador único opcional para la GroundImage (`String?`)
- **`extra`**: Datos adicionales adjuntos a la GroundImage (`Serializable?`)

## Mejores Prácticas

1. **Calidad de Imagen**: Asegurar que las imágenes de alta resolución se escalen bien
2. **Uso de Opacidad**: Elegir un nivel de opacidad apropiado para permitir que el mapa base sea visible
3. **Precisión de Límites**: Verificar que los límites de la imagen coincidan con la ubicación real en el mapa
4. **Rendimiento**: Monitorear el impacto en el rendimiento cuando se usan múltiples imágenes grandes simultáneamente
5. **Almacenamiento en Caché**: Almacenar en caché las imágenes que se cargan repetidamente para mejorar el rendimiento
6. **Carga Dinámica**: Para grandes conjuntos de imágenes, considerar cargar dinámicamente solo las imágenes visibles
7. **Índice Z**: Mantener el orden correcto de capas al superponer múltiples imágenes
