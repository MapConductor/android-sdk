Una GroundImage es una superposición de imagen posicionada geográficamente en un mapa. Es útil para mostrar planos de plantas, imágenes de satélite, superposiciones meteorológicas o datos basados en imágenes que deben anclarse a coordenadas geográficas específicas.

## Parámetros

- **`bounds`**: Límites rectangulares geográficos donde se posiciona la imagen (`GeoRectBounds`)
- **`image`**: Imagen dibujable para mostrar (`Drawable`)
- **`opacity`**: Nivel de opacidad de 0.0 (transparente) a 1.0 (opaco) (predeterminado: `0.5f`)
- **`id`**: Identificador único opcional para la GroundImage (`String?`)
- **`extra`**: Datos adicionales adjuntos a la GroundImage (`Serializable?`)
