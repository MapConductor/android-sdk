---
title: "PolygonState"
---

`PolygonState` gestiona los vértices del polígono, sus agujeros opcionales y el estilo de renderizado.

Propiedades comunes:

- `points: List<GeoPoint>`
- `holes: List<List<GeoPoint>>`
- `strokeColor`, `strokeWidth`
- `fillColor`
- `clickable`
- `extra`

Consulta [Polygon](/es-419/components/polygon) para ejemplos de cómo utilizarlo.
