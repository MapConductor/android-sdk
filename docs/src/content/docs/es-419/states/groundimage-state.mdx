`GroundImageState` gestiona la configuración y el comportamiento de overlays de imagen en el mapa. Proporciona propiedades reactivas para límites geográficos, recursos de imagen y niveles de opacidad.

## Propiedades

### Propiedades básicas
- **`id: String`**: Identificador único (se genera automáticamente si no se proporciona).
- **`bounds: GeoRectBounds`**: Límites rectangulares geográficos donde se coloca la imagen.
- **`image: Drawable`**: Imagen `Drawable` a mostrar.
- **`opacity: Float`**: Nivel de opacidad (0.0 = transparente, 1.0 = opaco).
- **`extra: Serializable?`**: Datos adicionales asociados al overlay.

## Buenas prácticas

1. **Tamaño de imagen**: Optimiza la resolución de la imagen para mejorar el rendimiento.
2. **Precisión de los límites**: Asegura una alineación geográfica precisa.
3. **Opacidad**: Usa un nivel de transparencia adecuado para mantener la visibilidad del mapa.
4. **Gestión de recursos**: Cachea y reutiliza recursos `Drawable` siempre que sea posible.
5. **Orden de capas**: Ten en cuenta el orden de dibujo cuando haya varios overlays.
6. **Rendimiento**: Limita el número de GroundImages simultáneos.
7. **Manejo de errores**: Gestiona correctamente los errores cuando falle la carga de imágenes.
