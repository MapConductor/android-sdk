---
title: "PolylineState"
---

`PolylineState` mantiene la lista de puntos y las propiedades visuales de una polilínea.

Propiedades típicas:

- `points: List<GeoPoint>`
- `color: Color`
- `width: Dp`
- `clickable: Boolean`
- `extra: Serializable?`

Sigue el mismo patrón de API que otros estados como `CircleState` y `MarkerState`.
