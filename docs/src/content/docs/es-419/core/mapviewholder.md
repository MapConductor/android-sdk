---
title: "MapViewHolder"
---

`MapViewHolder` actúa como puente entre la vista de mapa nativa y la capa de Compose. Gestiona referencias al objeto de mapa subyacente y coordina tareas internas como inicialización y destrucción.

Normalmente no necesitas interactuar con `MapViewHolder` directamente, pero es útil para extensiones avanzadas o depuración.
