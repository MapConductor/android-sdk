---
title: "Spherical Utilities"
---

`Spherical Utilities` proporciona funciones de ayuda para trabajar con coordenadas geográficas asumiendo la Tierra como una esfera.

## Casos de uso

- Calcular la distancia entre dos `GeoPoint`.
- Encontrar el punto intermedio o hacer interpolaciones.
- Calcular el rumbo (bearing) entre dos puntos.

Estas utilidades resultan útiles para rutas, animaciones de cámara y lógica de filtrado geográfico.
