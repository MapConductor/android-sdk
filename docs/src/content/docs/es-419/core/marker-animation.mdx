`MarkerAnimation` proporciona transiciones suaves y efectos visuales para los marcadores del mapa. Las animaciones pueden aplicarse a la apariencia del marcador, a cambios de posición y a eventos de ciclo de vida.

## Interfaz MarkerAnimation

<MarkerAnimationInterface />

## Tipos de animación

### Animación de posición

Anima de forma suave los cambios de posición de un marcador al actualizar sus coordenadas.

<PositionAnimationClass defaultDuration={1000} />

## Consideraciones de rendimiento

### Optimización de animaciones

1. **Limitar animaciones simultáneas**: Demasiadas animaciones a la vez pueden afectar al rendimiento.
2. **Duraciones adecuadas**: Animaciones excesivamente largas pueden percibirse como lentas.
3. **Interpoladores eficientes**: Algunos interpoladores tienen un coste de cálculo mayor.

## Mejores prácticas

### Guías de animación

1. **Proporcionar feedback**: Usa animaciones para dar feedback visual a las acciones del usuario.
2. **Mantener el contexto**: Las animaciones deben ayudar al usuario a entender las relaciones espaciales.
3. **Ser consistente**: Utiliza estilos de animación coherentes en toda la aplicación.
4. **Considerar la accesibilidad**: Ofrece opciones para reducir o desactivar animaciones.

## Solución de problemas

### Problemas comunes

1. **La animación no se inicia**: Comprueba que se llame a `MarkerState.setAnimation()`.
2. **Movimiento entrecortado**: Revisa la elección de interpolador y la frecuencia de cuadros.
3. **Fugas de memoria**: Asegúrate de limpiar animaciones cuando se eliminen marcadores.
4. **Problemas de rendimiento**: Limita el número de animaciones simultáneas y usa duraciones más cortas.
