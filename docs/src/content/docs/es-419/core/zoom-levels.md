---
title: "Zoom Levels"
---

Este documento explica la relación entre el nivel de zoom y la escala visual, y cómo MapConductor maneja el parámetro `zoom` de `MapCameraPosition`.

## Guía aproximada de niveles

- 5–7: nivel regional/provincia.
- 10–12: nivel ciudad.
- 15–17: nivel barrio/edificio.
- 18+: nivel de detalle alto.

Los valores exactos dependen del SDK de mapas, pero MapConductor ofrece una abstracción común.
