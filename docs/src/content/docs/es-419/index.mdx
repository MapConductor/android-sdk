## Ejemplo rápido

```kotlin
@Composable
fun MyMap() {
    val mapViewState = rememberGoogleMapViewState()

    GoogleMapsView(
        state = mapViewState,
        onMapClick = { geoPoint ->
            println("Clicked: ${geoPoint.latitude}, ${geoPoint.longitude}")
        }
    ) {
        Marker(
            position = GeoPointImpl.fromLatLong(37.7749, -122.4194),
            icon = DefaultIcon(label = "SF")
        )
    }
}
```

¿Quieres cambiar a Mapbox? Solo sustituye `rememberGoogleMapViewState()` por `rememberMapboxMapViewState()` y `GoogleMapsView` por `MapboxMapView`. El resto del código permanece igual.
