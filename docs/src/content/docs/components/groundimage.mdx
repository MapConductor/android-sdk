Ground images are image overlays that are positioned geographically on the map. They are useful for displaying floor plans, satellite imagery, weather overlays, or any image-based data that needs to be anchored to specific geographic coordinates.

## Parameters

- **`bounds`**: Geographic rectangular bounds where the image is positioned (`GeoRectBounds`)
- **`image`**: Drawable image to display (`Drawable`)
- **`opacity`**: Opacity level from 0.0 (transparent) to 1.0 (opaque) (default: `0.5f`)
- **`id`**: Optional unique identifier for the GroundImage (`String?`)
- **`extra`**: Additional data attached to the GroundImage (`Serializable?`)
