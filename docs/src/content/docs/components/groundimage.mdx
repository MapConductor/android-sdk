Ground images are image overlays that are positioned geographically on the map. They are useful for displaying floor plans, satellite imagery, weather overlays, or any image-based data that needs to be anchored to specific geographic coordinates.

## Parameters

- **`bounds`**: Geographic rectangular bounds where the image is positioned (`GeoRectBounds`)
- **`image`**: Drawable image to display (`Drawable`)
- **`opacity`**: Opacity level from 0.0 (transparent) to 1.0 (opaque) (default: `0.5f`)
- **`id`**: Optional unique identifier for the GroundImage (`String?`)
- **`extra`**: Additional data attached to the GroundImage (`Serializable?`)

## Best Practices

1. **Image Quality**: Ensure high-resolution images scale well
2. **Opacity Usage**: Choose an appropriate opacity level to allow the underlying map to be visible
3. **Boundary Accuracy**: Verify that the image bounds match the actual location on the map
4. **Performance**: Monitor performance impact when using multiple large images simultaneously
5. **Caching**: Cache images that are loaded repeatedly for performance
6. **Dynamic Loading**: For large image sets, consider dynamically loading only visible images
7. **Z-Index**: Maintain correct layer order when overlaying multiple images
